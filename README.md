# Image Slider

A simple image slider that fetches images from an API and displays them with slide controls and navigation dots.

## Features
- Fetches images dynamically from an external API
- Next/Previous slide controls
- Clickable navigation dots
- Smooth slide transitions

## Usage
Clone the repository and open `index.html` in your browser.

```bash
git clone https://github.com/MohammedGousemohiyuddinYekkaluru/Image-Slider.git
```
